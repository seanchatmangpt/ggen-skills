# Example: feature reconstitution

For a request to replace a legacy feature while preserving behavior:

```text
capability-orientation
-> preserve-fence
-> source-admission
-> observe-admit
-> contract-first
-> dfcm + adversarial-requirements
-> ggen-first
-> select-construct-do
-> brce-boundary (only if consequential actuation is requested/authorized)
-> evidence-receipts
-> exact-head-verification
-> replay-standing
-> reconstitution
```

A failed generator edge does not authorize a handwritten fallback automatically. DfCM retains other lawful edges and requires a new selection rationale.
