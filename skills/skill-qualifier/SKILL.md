# skill-qualifier

Run the cheapest high-information real gates first and expand after success.

## Use when

Qualify a skill against its exact version using trigger, procedural, authority, and consequence evidence. Use before promotion, publication, or claims that a skill is ALIVE.

## Inputs

- Exact skill identity.
- Acceptance/eval cases and target harness.

## Procedure

1. Verify static structure first.
2. Run trigger-positive and trigger-negative cases.
3. Execute the actual procedure on an admitted subject when the claim is operational.
4. Run authority/refusal cases for consequential paths.
5. Run replay or determinism checks where claimed.
6. Record commands/tools/results and assign bounded standing.

## Output

A qualification receipt with per-gate results and scoped standing.

## Falsifiers and refusals

- Static lint can prove structure, not end-to-end behavior.
- Do not substitute a unit check for requested integration/e2e proof.

## Composition

This skill may be composed by `aps-protocol`. Preserve explicit handoff state and do not infer authority across skill boundaries.
