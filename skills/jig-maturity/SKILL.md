# jig-maturity

Treat maturity as a vector, not an average.

## Use when

Assess manufacturing maturity as five levels across seven independent dimensions. Use to diagnose where a workflow still depends on craft knowledge despite sophisticated automation elsewhere.

## Inputs

- Workflow, factory, or skill system.
- Evidence for each manufacturing dimension.

## Procedure

1. Score each dimension independently: product knowledge, work positioning, operation guidance, process sequence, error prevention, measurement/qualification, adaptation/learning.
2. Use levels L1 Craft, L2 Template, L3 Fixture, L4 Jig, L5 Closed-Loop Manufacturing System.
3. Identify the lowest maturity dimensions and their evidence.
4. Generate upgrade candidates with DfCM rather than forcing uniform redesign.

## Output

A 7-dimensional maturity vector, evidence, bottlenecks, and candidate upgrades.

## Falsifiers and refusals

- A high average cannot hide an L1 critical dimension.
- Automation volume is not maturity without qualification and adaptation.
