# skill-creator-dfcm

Manufacture the largest useful reversible skill design frontier before choosing package boundaries.

## Use when

Create or redesign an Agent Skill using APS and DfCM. Use when adding a skill, converting a protocol into skills, improving triggering, or deciding between one broad skill and multiple composable skills.

## Inputs

- User outcome and examples.
- Existing skills and overlap graph.
- Target harness constraints.

## Procedure

1. Orient the target skill format and runtime.
2. Preserve existing useful trigger behavior and law.
3. Define the skill contract: trigger, inputs, procedure, output, refusals, evidence.
4. Enumerate atomic, composite, reference-backed, script-backed, and tool-backed candidates.
5. Prefer composition over duplicated law.
6. Select boundaries that preserve independent reuse and authority separation.
7. Write portable metadata plus operational body.
8. Create positive, negative, ambiguity, and adversarial eval cases.
9. Qualify triggering and execution; promote reusable patterns.

## Output

A skill package plus eval matrix, dependency/composition graph, and bounded standing.

## Falsifiers and refusals

- A large prompt is not automatically a skill architecture.
- Do not hide consequential authority inside convenience instructions.

## Composition

This skill may be composed by `aps-protocol`. Preserve explicit handoff state and do not infer authority across skill boundaries.
