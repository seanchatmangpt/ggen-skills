# governance-compression

Scale governance with law and evidence rather than projection count.

## Use when

Compress governance by validating bounded source classes and manufacturing law rather than manually reviewing every derived artifact. Use for high-scale generated systems, enterprise architecture, policy, or portfolio governance.

## Inputs

- Source classes, manufacturing patterns, authority policies, verifier laws, and projection families.

## Procedure

1. Define the bounded source classes that determine many projections.
2. Qualify each source class and its versioned scope.
3. Verify deterministic or bounded projection correspondence.
4. Sample or adversarially test projections to falsify the compression assumption.
5. Revalidate when source, generator, policy, or verifier identity changes.

## Output

A governance map from source-class admission to covered projections, exceptions, and revalidation triggers.

## Falsifiers and refusals

- “Validate once” never means permanent approval.
- Compression fails if projections can acquire uncontrolled semantics downstream.
